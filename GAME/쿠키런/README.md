# 과자 왕국 런 (Cookie Kingdom Run)

쿠키런 스타일의 2D 러너 게임입니다. 순수 HTML5 Canvas + Vanilla JavaScript로 만들어졌고, 빌드 도구나 외부 라이브러리 없이 `index.html` 하나로 동작합니다.

## 실행 방법

이미지·BGM을 `assets/` 폴더에서 불러오므로 **로컬 웹 서버**로 열어야 합니다. (파일을 더블클릭해서 `file://`로 열면 브라우저 보안 정책 때문에 BGM이 재생되지 않을 수 있습니다.)

```bash
# Python
python -m http.server 8000
# 또는 Node
npx serve .
```

그 다음 브라우저에서 `http://localhost:8000` 을 엽니다.

GitHub Pages에 올리면 별도 설정 없이 바로 플레이할 수 있습니다. (Settings → Pages → Branch: main, folder: / (root))

## 게임 구성

- **캐릭터 4종**: 초코칩 쿠키 용사, 딸기 쿠키, 민트 쿠키, 카라멜 쿠키 — 각각 속도·점프·스킬이 다릅니다.
- **스테이지 4개**: 벚꽃 숲, 캔디 언덕, 아이스크림 설산, 마녀의 호박 밤. 선택한 스테이지 하나만 달리며 한 판은 약 1분(결승선까지 19,000px)입니다.
- **난이도 4단계**: 쉬움 / 보통 / 어려움 / 지옥
- **지형 옵션**: 평지 / 오르막·내리막
- **3단 패럴랙스 배경**: 원경(0.12배) · 중경(0.45배) · 지면(1.0배) 속도로 각각 스크롤되어 입체감을 냅니다.
- **시스템**: ENERGY 게이지, 하트 3개, 콤보, 젤리·코인·보너스 아이템, 거대화 파워업, 따라다니는 펫(버프), 중간 보스, 결승선 클리어 보너스, 최고 기록(localStorage)

## 폴더 구조

```
index.html          게임 전체 (HTML + CSS + JS)
assets/
  run_*.png         달리기 스프라이트 시트 (캐릭터별)
  slide_*.png       슬라이드 포즈
  jump_*.png        점프 포즈
  hurt_*.png        피격 포즈
  win_*.png         승리 포즈
  far.jpg, scene2~4.jpg   원경 배경 (스테이지 1~4)
  mid.png, mid2~4.png     중경 배경 (투명 PNG)
  ground.png, ground2~4.png  지면 타일
  pet.png           펫 (젤리 아기 박쥐)
  boss1.png         보스 (꿀벌 여왕)
  bgm.mp3           배경음악 (가사 없음)
```

## 에셋 제작

- 캐릭터·배경·펫·보스 이미지: Google Gemini (Nano Banana) 로 생성 후 배경 제거·스프라이트 시트 정리
- BGM: Gemini Lyria 로 생성한 무가사 트랙
- 젤리·장애물·이펙트·효과음: 코드로 직접 그리고 합성 (WebAudio)
